# ⚔️ 교차로 대전 — 로블록스 라이벌 스타일 총게임

로블록스 라이벌(RIVALS)의 '교차로' 맵에서 영감을 받은 브라우저 FPS 게임입니다.
파랑팀(나 + 봇 2명) vs 빨강팀(봇 3명) 팀 데스매치로, 먼저 **25킬**을 달성하는 팀이 승리합니다.

## 실행 방법

- `game/index.html`을 브라우저에서 열면 바로 플레이할 수 있습니다.
  (모듈 로딩 때문에 로컬에서는 간단한 서버로 여는 것을 추천: `python3 -m http.server` 후 `http://localhost:8000/game/`)
- GitHub Pages가 켜져 있다면 `/game/` 경로에서 바로 플레이 가능합니다.
- 외부 CDN 없이 동작하도록 Three.js가 `lib/`에 포함되어 있어 오프라인에서도 실행됩니다.

## 조작법 (PC)

| 조작 | 키 |
|---|---|
| 이동 | W A S D |
| 점프 | Space |
| 달리기 | Shift |
| 발사 | 마우스 왼쪽 |
| 조준 (저격소총) | 마우스 오른쪽 |
| 재장전 | R |
| 무기 교체 | 숫자 1~6 또는 마우스 휠 |

## 조작법 (모바일)

휴대폰·태블릿에서 열면 터치 컨트롤이 자동으로 나타납니다. 가로 화면을 추천해요.

| 조작 | 방법 |
|---|---|
| 이동 | 왼쪽 화면 아무 곳이나 터치 후 드래그 (가상 조이스틱) |
| 달리기 | 조이스틱을 끝까지 밀기 |
| 시점 회전 | 오른쪽 화면 드래그 |
| 발사 | 🔥 버튼 (누르고 있으면 연사) |
| 점프 | ⬆ 버튼 |
| 조준 (저격소총) | 🎯 버튼 |
| 재장전 | ↻ 버튼 |
| 무기 교체 | 화면 아래 무기 이름 터치 |

## 무기 6종

| 슬롯 | 무기 | 특징 |
|---|---|---|
| 1 | 돌격소총 | 자동 연사, 밸런스형. 헤드샷 2배 |
| 2 | 샷건 | 근거리에서 펠릿 8발 산탄 |
| 3 | 저격소총 | 우클릭 줌, 한 방 90 (헤드샷 즉사) |
| 4 | RPG | 로켓 발사, 폭발 범위 피해 |
| 5 | 얼음 광선 | 지속 빔, 적을 느리게 만들고 결국 빙결시킴 |
| 6 | 수류탄 | 포물선 투척, 튕긴 뒤 폭발 |

## 맵: 교차로

- 두 개의 도로가 십자로 교차하는 대칭 맵
- 중앙 교차점의 깃발 플랫폼 (고지전)
- 네 모퉁이의 건물 — 계단으로 지붕에 올라가 저격 가능
- 도로 곳곳의 상자 엄폐물, 외곽 벽

## 기타 시스템

- 로블록스 스타일 블록 캐릭터 (이름표 + 체력바 표시)
- 킬 피드, 히트마커, 피격 시 화면 붉어짐, 폭발 카메라 흔들림
- 사망 시 3초 후 리스폰, 6초간 피해가 없으면 체력 자동 재생
- 효과음은 WebAudio로 실시간 합성 (외부 음원 파일 없음)
